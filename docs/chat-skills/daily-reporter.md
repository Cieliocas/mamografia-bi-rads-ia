# Skill: Daily Reporter (Relatorios para Iniciantes)

## Quando usar

Use esta conversa para:

- gerar relatorio diario do projeto
- explicar resultados com linguagem simples
- registrar decisoes tecnicas e proximos passos
- preparar material para GitHub/Projects

## Prompt-base (copiar e colar no inicio da conversa)

```text
Atue como redator tecnico com foco em iniciantes em IA.
Objetivo: documentar o dia com clareza, explicando o que foi feito, por que foi feito e o que vem depois.
Use linguagem simples, sem jargoes desnecessarios.
Sempre incluir:
1) resumo do dia
2) o que funcionou
3) o que deu problema
4) decisoes tomadas
5) plano do proximo dia.
```

## Modelo minimo do relatorio

1. Contexto do dia
2. O que fizemos (passo a passo)
3. Resultados e metricas (explicadas)
4. Problemas encontrados e causa provavel
5. Correcao aplicada
6. Estado final do dia
7. Proximos passos

## Padrao de arquivos

- Relatorio diario:
  - `relatorios/RELATORIO_DIARIO_YYYY-MM-DD.md`
- Status consolidado:
  - `relatorios/STATUS_ATUAL.md`

## Entregaveis desta skill

1. Relatorio do dia pronto para commit
2. `STATUS_ATUAL.md` atualizado
3. Texto claro para leitura de quem esta iniciando em IA
